# YouTube 視聴履歴ビューア

Google Takeout で書き出した YouTube の再生履歴を読み込み、**同じ動画を何回見たか / いつ初めて見たか / 繰り返し見た動画のランキング / チャンネル別の総再生回数 / そのチャンネルで初めて見た動画** などを表示する、ブラウザだけで動く静的サイトです。

履歴は**端末の外に出ません**。サーバーもビルドも不要で、`index.html` を開くだけで動きます。

---

## 使い方

### 1. 履歴を書き出す

1. [Google Takeout](https://takeout.google.com/) を開く
2. 「選択をすべて解除」→ **YouTube と YouTube Music** だけにチェック
3. 「含めるデータの選択」で **履歴** のみに絞る
4. 形式は **JSON** を選ぶ（HTML でも読めますが、JSON の方が速く正確です）
5. 書き出しを実行してファイルをダウンロード

### 2. 開く

- `index.html` をブラウザで開く（ダブルクリックで OK）
- もしくはローカルサーバー経由：

  ```sh
  python3 -m http.server 8000
  # → http://localhost:8000/
  ```

### 3. 読み込ませる

ダウンロードした次のいずれかをドロップします。**複数まとめてドロップできます。**

| 読み込めるもの | 例 |
| --- | --- |
| Takeout の zip（展開不要） | `takeout-20260812T000000Z-001.zip` |
| 再生履歴の JSON | `Takeout/YouTube と YouTube Music/履歴/再生履歴.json` |
| 再生履歴の HTML | `Takeout/YouTube と YouTube Music/履歴/再生履歴.html` |
| マイ アクティビティの HTML | `Takeout/マイ アクティビティ/YouTube/マイアクティビティ.html` |
| このアプリが書き出した統合 JSON | `youtube-history-merged_2026-08-12.json` |

zip はブラウザ内で必要な部分だけを取り出して展開するため、サイズが大きくても全体をメモリに載せません。
zip の中に履歴が複数入っている場合は、**全部読んでから**まとめます。

すぐ試したい場合は取り込み画面の「サンプルデータで試す」を押してください（生成した架空のデータです）。

---

## 複数のエクスポートをまとめる

YouTube の再生履歴は一定期間で消えていくため、**1 回のエクスポートには数か月分しか入っていません**。
しかも保持期間は年々短くなっています（実例：2024 年の書き出しでは約 9 か月分遡れたのが、
2026 年 8 月の書き出しでは約 1 か月分だけでした）。
そのため、**時期の違うエクスポートを取っておいて、まとめて読み込ませる**必要があります。

- 複数ファイルを一度に読み込むと、**同じ視聴（動画 ID と秒単位の時刻が一致するもの）を 1 件に畳んで**
  1 本の記録にします。読み込む順番は結果に影響しません。
- 分析画面の「**ファイルを追加**」で、後からエクスポートを足せます（置き換えではなく統合されます）。
- 「**統合データを書き出す**」で、まとめた結果を 1 本の JSON として保存できます。
  次からは **その統合 JSON と新しいエクスポートの 2 つだけ**を読み込ませれば済みます。

ヘッダーの件数表示にマウスを載せると、ファイルごとの件数・新規・重複の内訳が出ます。

### 視聴として数えないもの

読み込む時点で次を除外します。

| 除外するもの | 理由 |
| --- | --- |
| **広告**（`Google 広告から` / `From Google Ads`） | 自分で見た動画ではないため。日本語の書き出しでは英語表記が一切出てこないので、日本語の表記でも判定します |
| **検索の記録** | 視聴ではないため |
| **高く評価した・低く評価した・非表示にした** などの操作 | 動画リンクを持つので放っておくと視聴として数えられてしまう |
| **YouTube 以外のサービス**（検索・Chrome など） | 「マイ アクティビティ」の書き出しに混ざっているため。Google 検索の結果から YouTube を開いた記録が視聴に紛れ込むのを防ぎます |

## できること

### ダッシュボード
- 総再生回数、視聴した動画数・チャンネル数、再生に占める再視聴の割合
- 1本あたりの平均再生回数、視聴した日数、最長連続視聴日数、最も見た日、よく見る時間帯
- 月ごとの再生回数（**初めて見た** / **もう一度見た** の積み上げ）。
  **棒を選ぶと、その月の日ごとの内訳**（日別グラフ・見た日数・最も見た日・その月によく見たチャンネルと動画）を表示
- 「はじめて見たもの」の累計（動画・チャンネル）
- 曜日 × 時間帯のヒートマップ
- チャンネル別の再生回数 上位10 / 繰り返し見た動画 上位10

### 動画ランキング
- 再生回数・初めて見た日・最後に見た日・見続けた期間で並べ替え
- 行を選ぶと、**その動画を見たすべての日時**と前回からの間隔、月ごとの再生回数を表示

### チャンネル
- 総再生回数・視聴した動画数・1本あたりの再生回数のランキング
- **そのチャンネルで初めて見た動画**を一覧に表示
- 行を選ぶと、きっかけの動画・月ごとの再生回数・よく見た動画を表示

### はじめて見た記録
- チャンネルを見つけた順に並べた「開拓の記録」（きっかけの動画つき）
- 年ごとに初めて見た動画数・チャンネル数

### 履歴
- 日付ごとに区切った視聴履歴（各再生が「通算何回目」かをバッジ表示）

### 共通
- 期間（全期間 / 直近30日・90日・1年 / 年 / 任意の期間）、キーワード、YouTube Music の有無、ショート動画の有無で絞り込み
- 絞り込みはすべての画面・すべての集計に同時に反映されます
- 各表と各グラフは CSV / 表形式でも確認できます
- ライト / ダークの配色に対応

## 集計についての注意

- **重複のまとめ方**：YouTube は、途中まで見て開き直した場合や自動再生の場合に、同じ動画を短い間隔で複数回記録することがあります。初期設定では **5分以内の同じ動画は1回** として数えます。フィルタ行の「重複をまとめる」で `まとめない` / `30分` / `同じ日` に変更できます。
- **広告**は読み込む時点で捨てています（「視聴として数えないもの」参照）。集計にも書き出した統合 JSON にも含まれません。
- **複数のエクスポートを統合する場合**、同じ視聴かどうかは `動画 ID + 秒単位の時刻` で判定します。JSON はミリ秒、HTML は秒までしか持たないため、秒に丸めないと同じ視聴が二重に残ります。
- **ショート動画の判定は完全ではありません。** Takeout はショートも通常の動画と同じ `watch?v=` 形式で記録するため、URL からは区別できません（実データ 166,609 件のうち `/shorts/` 形式の URL は **0 件**でした）。そのため、投稿者がタイトルに付けた `#shorts` などのタグで判定しています。**タグの無いショートは通常の動画として数えられます。**「Beautiful shorts」のような普通の英単語を拾わないよう、`#` `＃` `@` や `【】` が付いたものだけを見ています。
- **削除・非公開になった動画**は Takeout 側でタイトルが失われるため、「（削除・非公開の動画）」と表示されます。動画 ID が残っていれば、それぞれ別の動画として数えます。
- **チャンネル情報のない記録**はチャンネル別集計に含まれません（動画としては数えます）。
- 履歴に**視聴時間は含まれません**。Takeout が持っているのは「いつ再生したか」だけなので、このアプリで扱うのはすべて**再生回数**です。
- 日時は**ブラウザのタイムゾーン**で表示します（HTML 形式の場合は、ファイル内のタイムゾーン表記を解釈して変換します）。

## プライバシー

- 読み込んだ履歴は**すべてブラウザの中だけ**で処理されます。通信は一切行いません（外部の CDN も使っていません）。
- 「このブラウザに保存する」を有効にした場合のみ、次回すぐ開けるように **IndexedDB**（端末内）へ保存します。ヘッダの「データを削除」でいつでも消せます。
- 動画タイトルやチャンネル名は必ずテキストとして挿入しているため、履歴内の文字列が HTML として実行されることはありません。

---

## 構成

ビルド不要・依存ライブラリなし。すべて素の HTML / CSS / JavaScript です。

```
index.html
assets/
  css/style.css
  js/
    utils.js      DOM 生成・整形・日付
    zip.js        最小限の ZIP リーダー（Blob.slice + DecompressionStream）
    parser.js     Takeout の JSON / HTML を視聴イベントに正規化
    analytics.js  絞り込み・重複のまとめ・集計
    charts.js     SVG チャート（積み上げ棒・横棒・折れ線・ヒートマップ）
    store.js      IndexedDB への保存
    demo.js       サンプルデータ生成
    views.js      画面ごとの描画
    app.js        取り込み・絞り込み・画面遷移
```

配色はライト / ダークとも、色覚特性のシミュレーションと背景とのコントラストを検証したパレットを使っています。すべてのグラフにホバー・キーボード操作・表形式の代替表示を用意しています。

### 動作環境

`DecompressionStream`（zip の展開）と `ResizeObserver` を使うため、次のバージョン以降が必要です。

- Chrome / Edge 105+、Firefox 113+、Safari 16.4+

zip に対応していないブラウザでは、展開後の JSON / HTML を読み込ませてください。

### 公開する場合

静的ファイルだけなので、GitHub Pages などにそのまま置けます（リポジトリの Settings → Pages で公開ブランチを指定するだけ）。サーバー側の処理は不要です。
