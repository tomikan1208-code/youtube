プライバシーについて

読み込んだ履歴はブラウザの中だけで処理されます。どこにも送信されません。 「このブラウザに保存する」を有効にした場合のみ、次回すぐ開けるように端末内（IndexedDB）へ保存します。保存したデータは「データを削除」でいつでも消せます。

複数のエクスポートをまとめる

YouTube の再生履歴は一定期間で消えていくため、1 回のエクスポートには数か月分しか入っていません。 時期の違うエクスポートを複数まとめて読み込ませると、同じ視聴（動画 ID と秒単位の時刻が一致するもの）を 1 件に畳んだうえで、全期間をつないだ 1 つの記録になります。

まとめた結果は「統合データを書き出す」で 1 本の JSON として保存できます。 次からは その統合 JSON と新しいエクスポートの 2 つだけを読み込ませれば済みます。 広告（「Google 広告から」の記録）は視聴ではないので、読み込む時点で除外します。

履歴の書き出し方

  1. Google Takeout を開く
  2. 「選択をすべて解除」してから YouTube と YouTube Music だけを選ぶ
  3. 「含めるデータの選択」で 履歴 のみに絞る（動画などを含めると zip が数 GB になります）。形式を JSON にすると解析が速く正確です
  4. 書き出した zip、または中の 履歴/再生履歴.json をここに読み込ませる
  5. 保持期間は年々短くなっています。3 か月に 1 回は書き出して、古いファイルも消さずに残してください。

すべての処理はこのブラウザの中だけで行われます。履歴データが外部に送信されることはありません。
